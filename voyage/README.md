# 远洋志（微信小游戏）

大航海题材的原创微信小游戏。玩家扮演十六世纪初的一名年轻船长，在欧洲、地中海、非洲和印度洋之间跑商、探索未知海域、与海盗交战，寻找绕过非洲通往印度和香料群岛的航路。

> 游戏名「远洋志」是暂定名，修改 `js/scenes/title.js` 里的标题文字即可。

## 试玩版 0.2 的内容

竖屏游戏，设计宽度 750（与小程序 rpx 一致），高度随手机比例自适应，适配刘海屏和右上角胶囊按钮。


- **港口**：31 座（北欧、伊比利亚、地中海、大西洋诸岛、西非、南非、东非、阿拉伯、印度、马六甲），开局知道 18 座，其余 13 座要出海发现
- **交易**：34 种商品。离产地越远越值钱；港口有各自需要的商品；同一种货卖多了会降价，过段时间恢复；随机出现“流行”商品
- **船只**：7 种船型（柯克船、三角帆卡拉维尔、达乌船、横帆卡拉维尔、加莱桨帆船、卡拉克帆船、盖伦帆船），船队最多 4 艘，可修理、出售、改名
- **航海**：点击港口或海面自动规划航线；信风、西风带、赤道无风带、印度洋季风会影响航速，横帆、三角帆、桨帆受风影响不同；粮食和淡水按船员人数每天消耗，与货物共用船舱；长期航海会得坏血病
- **探索**：未探索海域被迷雾覆盖；23 处发现物（海角、岛屿、火山、遗迹等），到酒馆报告可领奖金
- **随机事件**：风暴、海盗、无风、鼠患、热带骤雨、漂流物等
- **海战**：回合制，远/中/近三档距离，可炮击、靠近、拉开、接舷、撤退；接舷获胜可以俘获敌船
- **酒馆**：招募水手、接运货委托、打听消息（流行商品、未知港口、发现物线索）、报告发现
- **成长**：交易/探险/战斗三种名声和称号；交易等级带来价格优惠；大船需要名声才能购买；16 个航海目标
- **存档**：入港、每 5 天航行、切到后台时自动存档；菜单里也可以手动保存

## 在微信开发者工具里运行

1. 下载安装「微信开发者工具」。
2. 选择「导入项目」，目录选本仓库的 `voyage/` 文件夹。
3. AppID 填你自己的小游戏 AppID；还没有的话可以先选「测试号」。
4. 导入后点「编译」就能在模拟器里玩；点「预览」或「真机调试」可以扫码在手机上玩。

`project.config.json` 已开启「ES6 转 ES5」和「增强编译」，代码使用 ES Module 写法，不需要额外的游戏引擎或 npm 依赖。

## 在浏览器里预览

```bash
cd voyage
python3 -m http.server 8000
```

打开 <http://localhost:8000/>。电脑上会在中间显示竖屏比例的画面，可以用鼠标滚轮缩放地图。

也可以打包成单个 HTML 文件（方便发给别人试玩）：

```bash
cd tools
npm install
npm run web      # 输出 dist/yuanyangzhi-web.html
```

## 目录结构

```
voyage/                  微信小游戏项目根目录
├── game.js              入口
├── game.json            小游戏配置（竖屏）
├── project.config.json  开发者工具项目配置
├── index.html           浏览器预览入口（上传时会被忽略）
└── js/
    ├── main.js          主循环、场景切换、对话框、触摸分发
    ├── platform.js      平台适配（微信 / 浏览器）
    ├── ui.js            画布 UI：按钮、面板、滚动列表、滑块
    ├── theme.js         配色与字体
    ├── assets.js        美术与音频资源清单 ← 替换素材改这里
    ├── data/            游戏数据：港口、商品、船只、发现物、地图
    ├── systems/         游戏规则：寻路、风、市场、航行、事件、海战、委托、目标、存档
    ├── render/          航海图绘制、占位画面（船、港口、人物剪影）
    ├── panels/          港口设施面板：交易所、造船厂、酒馆、补给所、船队与日志
    └── scenes/          画面：标题、新游戏、港口、航海、海战
tools/                   构建脚本（生成地图数据、打包网页版），不进小游戏包
```

## 替换美术和音乐

现在的画面全部是程序绘制的占位效果，没有音乐。素材做好后：

1. 把图片放进 `voyage/images/`，音频放进 `voyage/audio/`。
2. 打开 `voyage/js/assets.js`，把对应项的 `null` 改成文件路径，例如 `title_bg: 'images/title_bg.jpg'`。
3. 重新编译。没有填路径的项继续用占位画面。

| 资源 | 用途 | 建议规格 |
| --- | --- | --- |
| `title_bg` | 标题画面背景（竖屏） | 1080×1920 |
| `port_europe` / `port_med` / `port_islands` / `port_africa` / `port_arabia` / `port_india` | 六种港口插画（按海域自动选用，显示在画面上半部分，会按比例裁切） | 1500×1300 |
| `battle_bg` | 海战背景（竖屏） | 1080×1920 |
| `map_ship` | 航海图上的船，船头朝右 | 128×128 透明 PNG |
| `battle_<船型>` | 海战中的船（7 种，侧视，船头朝右） | 512×512 透明 PNG |
| `npc_market` / `npc_shipyard` / `npc_tavern` / `npc_supply` | 设施人物立绘 | 600×800 透明 PNG |
| `bgm_title` / `bgm_port` / `bgm_sea` / `bgm_battle` | 背景音乐（循环） | mp3 |
| `sfx_click` / `sfx_coin` / `sfx_cannon` / `sfx_storm` / `sfx_discover` / `sfx_bell` | 音效 | mp3，尽量短小 |

注意：微信小游戏主包有体积上限（目前约 4MB）。背景图和音乐较大时，需要改用分包或把资源放到 CDN 上按需下载，到时候可以再调整加载方式。

## 修改游戏数据

- 港口：`js/data/ports.js`（坐标、特产、需求商品、造船厂船型、介绍文字）
- 商品：`js/data/goods.js`
- 船只：`js/data/ships.js`
- 发现物：`js/data/discoveries.js`
- 海盗、风暴等事件：`js/systems/events.js`
- 价格公式：`js/systems/market.js`

修改港口坐标或新增港口后，需要重新生成停泊点数据：

```bash
cd tools
npm install
npm run geo      # 重新生成 voyage/js/data/geo.js
```

## 关于地图

- 海岸线数据来自 Natural Earth（公有领域），由 `tools/build-geo.mjs` 处理成航海图和航行网格。
- 航海图只画海岸线、港口和海域名称，**不画国界**。
- 当前地图东边到马六甲为止，不包含中国沿海。以后扩展到东亚时，必须完整画出中国领土（包括台湾、海南、南海诸岛），以免被认定为“问题地图”。
